# Plantilla para reportar un problema

Esta plantilla la completa TU AGENTE (no vos a mano) cuando algo se traba y decidís dejarlo registrado — sea en Discord o como issue de GitHub (ver `COMO-PEDIR-AYUDA.md`). Mismo formato para los dos lugares, así quien lo lee no tiene que adivinar qué falta.

```markdown
## Fase / nivel donde pasó
[ej: Nivel 03 — Segundo cerebro, sección "Instalando Obsidian"]

## Qué se intentó
[el paso exacto, o el bloque de "decile esto a tu agente" que se usó]

## Qué pasó
[el resultado real — un mensaje de error copiado tal cual, o qué hizo la persona, o qué dijo el agente]

## Qué se esperaba que pasara
[según la guía, qué tendría que haber pasado en vez de eso]

## Evidencia
[opcional pero ayuda mucho: texto del error copiado y pegado, o una descripción de lo que se ve en pantalla — no hace falta una captura de pantalla si es más fácil describirlo]

## Sistema
[Windows / Mac / Linux, y qué agente se está usando — Claude Code, Codex CLI, etc.]
```

## Antes de reportar

Fijate primero en `PROBLEMAS-FRECUENTES.md` — puede que ya esté resuelto y documentado ahí. Si no está, recién ahí completá esta plantilla y seguí `COMO-PEDIR-AYUDA.md` para dónde postearla.
