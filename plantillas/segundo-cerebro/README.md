# Segundo cerebro — convención mínima

- Una nota por tema, en un archivo `.md` con nombre descriptivo (`kebab-case`, ej. `mi-tema-real.md`).
- Encabezado simple arriba de cada nota (ver `_ejemplo-nota.md`).
- Links a notas relacionadas — si usás Obsidian, `[[nombre-de-la-nota]]`; si no, simplemente nombrala en el texto.
- Nunca borrar una nota vieja porque "ya no aplica" — mejor agregar una aclaración arriba (`> Nota: esto cambió, ver [nota nueva]`) y dejar el rastro.
